### 3단계 · 통계값 산출 ✅

**처리 규모** (`03.통계값작성.ipynb`)

- 처리 문서: **7,162개** (대법원 판례 txt + 법률 정제 완료 txt 통합)
- 발견된 고유 형태소 (단어+품사 쌍): **99,550개**

**산출 지표**

| 지표 | 설명 |
|------|------|
| TF (단어 빈도) | 말뭉치 전체 출현 횟수 |
| DF (문서 빈도) | 해당 단어가 등장한 문서 수 |
| TF-IDF | 평균 가중치 (낮을수록 변별력 없음) |
| Entropy | 분포 무작위성 (높을수록 잡음) |
| MP (평균 확률) | 문서 내 평균 등장 확률 (높을수록 기능어성) |
| VP (분산) | 등장 확률의 분산 (낮을수록 안정적 불용어) |

출력 파일: `legal_corpus_stats_all_pos.pkl`, `legal_corpus_stats_all_pos.csv`, `legal_stopword_analysis_final.csv`

### 4단계 · 불용어 후보 추출 ✅

총 **3가지 도메인** × **3가지 주요 기법** + **합집합/교집합** 조합으로 후보 생성.
Kneedle 알고리즘(엘보우 포인트)으로 자동 컷오프 결정.

#### 공통 (판례 + 법령 통합) — `stopword_공통/`

| 기법 | 코드 | 컷오프 | 단어 수 |
|------|------|--------|---------|
| 고빈도(Zipf) | Exp A | Top 167위 ('책임') | 167개 |
| 엔트로피 | Exp B | Top 226위 ('기본') | 226개 |
| 안정성(MP-VP) | Exp C | Top 54위 ('담당') | **54개** |
| 합집합 | Exp D | — | — |
| **교집합(Golden)** | **Exp E** | — | **44개** |

#### 판례 전용 — `stopword_판례/`, `stopword_판례_통합/`

| 기법 | 코드 | 단어 수 |
|------|------|---------|
| 고빈도(Zipf) | Exp A | 132개 |
| 엔트로피 | Exp B | 83개 |
| 안정성(MP-VP) | Exp C | 143개 |
| **교집합(Golden)** | **Exp E** | **62개** |

#### 법령 전용 — `stopword_법령/`

| 기법 | 코드 | 단어 수 |
|------|------|---------|
| 고빈도(Zipf) | Exp A | 90개 |
| 엔트로피 | Exp B | 77개 |
| 안정성(MP-VP) | Exp C | 129개 |
| **교집합(Golden)** | **Exp E** | **48개** |

#### 공통 상세분석 (6개 단독 지표) — `stopword_공통_상세분석/`

TF, IDF, MP, VP, Entropy, MPVP를 각각 단독으로 분석하여 `불용어_상세분석_리포트.xlsx` 생성.

### 5단계 · 전문가 정제 (Human-in-the-loop) ⏳

**현황: 미완료**

- 전문가 검토 요청용 엑셀 파일은 생성 완료
- 변호사 또는 법학 박사 1~2인의 실제 검토 작업 대기 중

검토 기준: "이 단어가 판례의 요지나 법령의 해석을 가르는 핵심 키워드인가?"
예시: `경우`, `사항` → 삭제 승인 대상 / `고의`, `과실` → 삭제 반려 (법적 요건)

---

### 6단계 · 성능 검증 (벤치마크) ✅ / ⏳

모델: TF-IDF + Logistic Regression (5회 반복 평균), Top 10 사건 분류
관련 노트북: `05.벤치마크_테스트.ipynb`

#### LCC — 판례 분류 결과 (`benchmark_results_unified_top10.csv`)

| 순위 | 실험 | 단어 수 | Accuracy | F1 |
|------|------|---------|----------|----|
| 1 | Baseline (None) | 0 | **0.8772** | 0.8746 |
| 2 | [공통] Exp C (MPVP) | 54 | 0.8762 | 0.8736 |
| 3 | General Only | 600 | 0.8751 | 0.8727 |
| 4 | [법령] Exp B (Entropy) | 77 | 0.8751 | 0.8725 |
| 5 | [공통] Exp E (교집합) | 44 | 0.8751 | 0.8726 |

> 핵심 관찰: 불용어 제거 시 성능 저하가 없거나 소폭 개선됨. [공통] Exp C(MPVP, 54개)가 Baseline 대비 근소하게 높은 성능.

#### LCC — 판례 분류 결과 (`benchmark_results_precedent_top10_robust.csv`)

| 순위 | 실험 | Accuracy | F1 |
|------|------|----------|----|
| 1 | Baseline (None) | **0.6982** | 0.6936 |
| 2 | General Only | 0.6923 | 0.6888 |
| 2 | [공통] Exp C (MPVP) | 0.6923 | 0.6878 |
| 2 | [공통] Exp E (교집합) | 0.6923 | 0.6878 |

#### LST — 법령 분류 결과 (`benchmark_results_statute_top10_robust.csv`)

| 순위 | 실험 | Accuracy | F1 |
|------|------|----------|----|
| 1 | **[법령] Exp C (MPVP)** | **0.8061** | 0.8092 |
| 2 | **[법령] Exp A (Zipf)** | **0.8061** | 0.8073 |
| 3 | Baseline (None) | 0.7857 | 0.7871 |

> 핵심 관찰: **법령 분류에서는 법령 전용 불용어 적용 시 Baseline 대비 +2%p 성능 향상** (Exp C MPVP, Exp A Zipf). 법령 도메인 특화 불용어의 효용이 확인됨.

**미완료 평가 태스크**

- LST (Legal Statute Prediction) — LBOX 벤치마크 기준 법령 예측 (키워드 보존 여부) 미수행
- BERT 기반 법률 모델(KR-BERT-SC 등)을 이용한 딥러닝 성능 비교 미수행
